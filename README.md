# 🚀 JANSETU

**JANSETU** is an AI-powered legal and government schemes assistant designed to bridge the gap between citizens and public services. It simplifies complex legal information and government welfare schemes into easy-to-understand language, enabling users to quickly access reliable guidance and discover benefits they are eligible for.

The application combines Artificial Intelligence, semantic search, and multilingual support to provide a seamless experience for users seeking information about laws, citizen rights, and government schemes.

---

## ✨ Key Features

### 🤖 AI Legal Assistant

* Ask legal questions in natural language.
* Receive simplified explanations of legal rules and citizen rights.
* Covers topics such as employment, tenancy, education, consumer rights, and more.

### 🏛 Government Scheme Explorer

* Browse and search Central and State government schemes.
* View eligibility criteria, required documents, benefits, application process, and official websites.
* Filter schemes by category and government level.

### 🔍 Smart Search

* AI-assisted search for both legal information and government schemes.
* Fast and accurate retrieval using semantic search techniques.

### ❤️ Saved Schemes

* Bookmark schemes for quick access later.
* Persistent storage using local device storage.

### 🌐 Multilingual Support

* Translate scheme information into regional languages.
* Makes government information more accessible to a wider audience.

### 📱 Modern Mobile Experience

* Clean and intuitive React Native interface.
* Smooth animations and responsive UI.
* User-friendly design for all age groups.

---

## 🎯 Problem Statement

Citizens often struggle to:

* Understand complicated legal terminology.
* Find the right government schemes for their needs.
* Determine their eligibility for welfare schemes.
* Navigate multiple government portals for reliable information.

JANSETU addresses these challenges by providing a single intelligent platform that delivers simplified legal guidance and personalized scheme information.

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/Maa8nya/JANSETU.git
cd JANSETU
```

### Backend

```bash
cd backend
python -m venv venv

# Windows
venv\Scripts\activate

pip install -r requirements.txt

python app.py
```

### Frontend

```bash
cd ../frontend

npm install

npm start
```

Open the application using the **Expo Go** app or an Android Emulator.
